EBM System — النسخة المجهزة لمشروع Firebase emtr-10091
====================================================

تم وضع إعدادات تطبيق الويب التي أرسلتها ومفتاح Web Push العام في الملفات، وتم ضبط المشروع على emtr-10091 واستخدام مسار بيانات مستقل اسمه ebmSystem حتى لا يقرأ أو يغيّر بيانات مشروعك القديم.

المتبقي قبل التشغيل:
1) افتح https://console.firebase.google.com/project/emtr-10091/database وأنشئ Realtime Database إن لم تكن موجودة.
2) انسخ رابط قاعدة البيانات الحقيقي من صفحة Data (يكون عادةً عنوانًا ينتهي بـ firebasedatabase.app أو firebaseio.com).
3) افتح index.html وfirebase-messaging-sw.js واستبدل النص PASTE_REALTIME_DATABASE_URL_HERE بنفس رابط قاعدة البيانات في الملفين.
4) من Realtime Database > Rules انشر قواعد database.rules.json للاختبار فقط. تحذير: القواعد الحالية تسمح بالقراءة والكتابة العامة تحت ebmSystem، وهي غير آمنة لموقع عام أو بيانات حساسة. قبل الاستخدام الحقيقي يجب إضافة تسجيل دخول وقواعد آمنة.
5) ارفع محتويات المجلد على استضافة HTTPS (مثل Firebase Hosting أو GitHub Pages). جرّب إضافة ماكينة، إرسال بلاغ، ثم تسجيل وصول الفني وإنهاء الإصلاح.
6) لتفعيل إشعارات الخلفية: افتح الموقع على Chrome/Android، اضغط «تفعيل الإشعارات» واسمح بها. الإشعارات عند إغلاق الموقع تحتاج أيضًا نشر Cloud Function الموجودة في functions؛ لم يتم نشرها تلقائيًا لأن ذلك يتطلب تسجيل دخول Firebase CLI إلى حسابك ونشرها من حسابك.

الميزات: إدارة الماكينات، بلاغات الأعطال، حالة البلاغ (جديد/وصل الفني/تم الإصلاح)، سجل الصيانة، مزامنة فورية بين الأجهزة، تنبيه داخل الصفحة وصوت، وتسجيل أجهزة الإشعارات.

مهم:
- مفتاح VAPID الموجود هو المفتاح العام فقط.
- لا تشارك Service Account private key أو أي مفتاح خاص.
- هذه الحزمة لا تنشئ قاعدة البيانات ولا تنشر Cloud Function نيابة عنك؛ ذلك يتطلب الدخول إلى حساب Firebase الخاص بك.
