EBM System — نسخة جديدة كاملة متصلة بقاعدة Firebase
====================================================

المميزات الموجودة:
- لوحة تحكم وإحصائيات للماكينات وسجلات الصيانة.
- إضافة ماكينة وتعديل بياناتها وحذفها والبحث عنها.
- بلاغ توقف: اختيار الماكينة، اسم العامل، وصف العطل، وأولوية البلاغ.
- متابعة البلاغ: الفني يسجل الوصول ثم يسجل إتمام الإصلاح.
- تسجيل الصيانة: التاريخ، اسم الفني، التكلفة، العطل، والإجراء الذي تم.
- تحديث حالة الماكينة تلقائيًا عند البلاغ وعند إتمام الإصلاح.
- مزامنة مباشرة بين الأجهزة عبر Firebase Realtime Database.
- تنبيه داخل الموقع وصوت وإشعار متصفح عند وصول بلاغ جديد والصفحة مفتوحة.
- تسجيل جهاز للإشعارات بالخلفية عبر FCM، مع إعدادات Cloud Function منفصلة.
- تصدير نسخة احتياطية JSON من بيانات النظام.

الاتصال بقاعدة البيانات:
- المشروع المضبوط في هذه النسخة هو sstmy-627dc.
- المسار المستخدم للحفاظ على توافق البيانات القديمة هو ibmSystem/state.
- لا تحذف المسار ibmSystem ولا تنشئ مشروع Firebase جديدًا إذا كنت تريد الاحتفاظ بالبيانات الموجودة.

التثبيت:
1. فك الضغط.
2. ارفع الملفات الموجودة داخل مجلد EBM_System إلى جذر موقع GitHub Pages، مع استبدال ملفات الموقع القديمة.
3. افتح Firebase Console واختر مشروع sstmy-627dc ثم Realtime Database ثم Rules.
4. تأكد أن القواعد المنشورة مطابقة لملف database.rules.json واضغط Publish عند الحاجة.
5. افتح الموقع على HTTPS وحدّث الصفحة. يجب أن تظهر رسالة «متصل بقاعدة البيانات ✓».
6. جرّب إضافة ماكينة، ثم إرسال بلاغ، ثم تسجيل صيانة. افتح الموقع على جهاز آخر للتأكد من المزامنة.

قواعد الاختبار الحالية تسمح بالقراءة والكتابة للجميع تحت ibmSystem، وهي غير آمنة لبيانات المصنع الحقيقية. لا تستخدمها في بيئة إنتاج قبل إعداد Firebase Authentication وقواعد صلاحيات مقيدة.

إشعارات الخلفية:
- افتح الموقع على كل جهاز، واضغط «تفعيل الإشعارات والصوت» واسمح بإشعارات المتصفح.
- وصول الإشعارات حتى عندما تكون الصفحة مغلقة يتطلب نشر Cloud Function من مجلد functions باستخدام Firebase CLI، وقد يتطلب خطة Blaze وفوترة. هذه الخطوة ليست منشورة تلقائيًا بمجرد رفع ملفات GitHub Pages.

استكشاف الأخطاء:
- إذا ظهرت Permission denied: راجع القواعد المنشورة في Realtime Database.
- إذا لم تظهر رسالة الاتصال: تأكد من الإنترنت وأن الموقع يعمل على HTTPS.
- إذا تم إرسال البلاغ ولم يظهر على جهاز آخر: تأكد أن الجهازين يستخدمان نفس نسخة الموقع ونفس مشروع Firebase.
